# Sites de clientes

Prévias dos sites em andamento, publicadas pelo GitHub Pages. Cada cliente tem a sua pasta, com um `index.html` e uma pasta `assets/`.

| Cliente | Pasta | Prévia |
|---|---|---|
| Veras Empreendimentos | `veras/` | `/veras/` |

As prévias levam `noindex` para não aparecerem no Google. Tire essa linha do `index.html` quando o site for para o domínio oficial do cliente.
